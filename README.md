# NextBites

NextBites is a searchable recipe collection with a detail page for each recipe.

## Live site

[https://harshascreation.github.io/NextBites/](https://harshascreation.github.io/NextBites/)

The `main` branch is built and deployed to GitHub Pages by GitHub Actions.

## Run locally

```bash
npm ci
npm run dev
```

## Validate and build

```bash
npm run lint
npm run build
```
